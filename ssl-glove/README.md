# SSL Glove Mobile App

Frontend prototype for the SSL GLOVE smart glove app. It includes login/register flows and the Home, Language, and User tabs.

## Requirements

- Node.js and npm
- Expo Go (for running on a device)

## Scripts

- npm run start
- npm run android
- npm run ios
- npm run web

## Notes

- This is a UI-first prototype. Wire up real auth, device data, and gesture recognition when backend services are available.
